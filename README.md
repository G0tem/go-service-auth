# go-service-auth

Сервис авторизации. 
Предназначен для тестирования различных инструментов.  
Авторизация реализована через JWT токен - этот же токен используется в сервисе ```go-servise-entity```  

Реализован gRPC сервер в который обращается сервис ```go-servise-entity``` и http.  

CI/CD настроен на тестовый сервер.
доступ к документации (если внешний аpi до сих пор оплачен :) доступен по ```http://176.123.164.164:8080/api/v1/docs```  
Запросы идут через Traefik
